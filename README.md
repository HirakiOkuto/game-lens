# game-lens — แปลข้อความในเกมเป็นภาษาไทยแบบเรียลไทม์ แสดงทับบนหน้าจอเกม

game-lens อ่านข้อความในเกม (บทพูด ชื่อผู้พูด ตัวเลือกคำตอบ เมนู) แล้วแสดงคำแปลภาษาไทยทับตำแหน่งเดิมบนหน้าจอเกม
รองรับเกมภาษาญี่ปุ่น เกาหลี จีนตัวย่อ จีนตัวเต็ม และอังกฤษ

โปรแกรมไม่แก้ไขไฟล์เกม ไม่อ่านหน่วยความจำ และไม่ฉีดโค้ดเข้าเกม ใช้เพียงการจับภาพหน้าต่าง (Windows Graphics Capture
แบบเดียวกับโปรแกรมอัดหน้าจอ) และหน้าต่างโปร่งใสที่คลิกทะลุได้ซึ่งวางทับหน้าต่างเกม

หน้าต่างของโปรแกรมใช้ได้ทั้งภาษาอังกฤษ (ค่าเริ่มต้น) และภาษาไทย เปลี่ยนได้ที่มุมขวาบนของหน้าต่าง

## สิ่งที่ต้องมี

- Windows 10 หรือ 11 และอินเทอร์เน็ตสำหรับการเปิดใช้ครั้งแรก
- เกมต้องตั้งเป็นแบบ **Borderless** หรือ **Windowed** (ไม่สามารถแสดงทับโหมด Exclusive Fullscreen ได้)
- โมเดลแปลภาษาในเครื่องใช้ได้ทั้งเครื่องที่มีและไม่มีการ์ดจอ โปรแกรมเลือกรุ่นให้ตามหน่วยความจำการ์ดจอ (ดูหัวข้อ "เครื่องแปล")

## ติดตั้ง

### แบบ portable (แนะนำ)

1. แตกไฟล์ `game-lens-portable-<วันที่>.zip` ไว้ในโฟลเดอร์ที่เขียนไฟล์ได้ เช่น `D:\game-lens` (ไม่ควรไว้ใน Program Files)
2. ดับเบิลคลิก **game-lens.exe**
3. หาก Windows แสดง "Windows protected your PC" ให้กด **More info** แล้วกด **Run anyway** (โปรแกรมไม่ได้ลงลายเซ็นดิจิทัล)

ในชุด portable มี Python ส่วนประกอบทั้งหมด และ llama.cpp (Vulkan ใช้ได้กับการ์ดจอทุกยี่ห้อ) ไม่ต้องติดตั้งเพิ่ม
เมื่อเปิดครั้งแรก โปรแกรมจะดาวน์โหลดไฟล์ต่อไปนี้เอง โดยแสดงความคืบหน้าในหน้าต่าง game-lens

| ไฟล์ | ขนาด | เมื่อใด |
|---|---|---|
| ตัวอ่านข้อความ (ภาษาญี่ปุ่น จีน อังกฤษ) | ~87 MB | ครั้งแรกที่เปิดใช้งาน |
| ตัวอ่านข้อความภาษาเกาหลี | ~18 MB | ครั้งแรกที่เลือกเกมภาษาเกาหลี |
| โมเดลแปลภาษา | 1.1–5.8 GB ตามรุ่น | ครั้งแรกที่ใช้โมเดลแปลภาษาในเครื่อง |

หากการดาวน์โหลดหยุดกลางคัน ให้เปิดโปรแกรมใหม่ ระบบจะดาวน์โหลดต่อจากเดิม

### แบบติดตั้งจากโค้ด

1. ติดตั้ง [Python 3.14](https://www.python.org/downloads/)
2. แตกไฟล์ `game-lens-<วันที่>.zip` แล้วดับเบิลคลิก **setup.bat**
3. หาก setup แจ้งว่าไม่พบคำสั่ง `llama` และต้องการใช้โมเดลแปลภาษาในเครื่อง ให้ติดตั้ง
   [Llama for Windows](https://github.com/ggml-org/Llama-Windows/releases) (ไฟล์ `.msixbundle` ล่าสุด)
4. ดับเบิลคลิก **start.bat** เพื่อเปิดโปรแกรม

### ไอคอนบนเดสก์ท็อป

กดปุ่ม **Desktop icon / สร้างไอคอนบนเดสก์ท็อป** ในหน้าต่าง game-lens ครั้งต่อไปดับเบิลคลิกไอคอน game-lens เพื่อเปิดได้ทันที
game-lens เปิดระบบแปลภาษาและโมเดลให้เอง และปิดให้เมื่อกด **Quit / ปิดโปรแกรม**

## การตั้งค่าครั้งแรก (3 ขั้นตอน)

หน้าต่าง game-lens แสดงสถานะของแต่ละขั้นตอน (จุดสีเขียว = พร้อม) พร้อมปุ่มสำหรับขั้นตอนที่ยังไม่เสร็จ

1. **ระบบแปลภาษา** — เปิดเองโดยอัตโนมัติ โปรดรอจนแสดง "พร้อมใช้งาน"
2. **เกม** — กด **เลือกเกม** แล้วเลือกจากรายการ หรือกด **ตรวจจับอัตโนมัติ** แล้วสลับไปยังหน้าต่างเกมภายใน 5 วินาที
3. **กรอบข้อความ** — ไปยังหน้าที่มีบทพูดในเกม แล้วกด **ตั้งกรอบ** (หรือกด F10)
   - โปรแกรมจะค้นหาข้อความบนหน้าจอและแสดงเส้นประ คลิกที่บทพูดหนึ่งครั้งเพื่อสร้างกรอบ แล้วคลิกที่ชื่อผู้พูด
   - ลากที่ว่าง = สร้างกรอบใหม่ • ลากกรอบ = ย้าย • ลากมุมขวาล่าง = ปรับขนาด
   - กด 1 / 2 / 3 / 4 = บทพูด / ชื่อผู้พูด / คำบรรยาย / ตัวเลือกคำตอบ • Delete = ลบ • Enter = บันทึก
   - คลิกขวาที่กรอบเพื่อเลือกสีตัวอักษร (ตัวเข้มบนพื้นสว่าง) หรือจัดกึ่งกลาง
   - บทพูดที่แสดงกลางจอทับฉากเกม (ไม่มีกล่องข้อความ) ใช้ได้เช่นกัน กรอบบทพูดควรครอบได้ 3 บรรทัด

เมื่อครบทั้ง 3 ขั้นตอน โปรแกรมจะเริ่มแปลโดยอัตโนมัติ และจดจำการตั้งค่าไว้ ครั้งต่อไปเพียงเปิดเกม
โปรไฟล์ของ Azur Promilia มีกรอบข้อความตั้งไว้ให้แล้ว (วัดจากเกมรุ่น CBT สัดส่วนจอ 16:9)

## ระหว่างเล่น

| ปุ่ม | การทำงาน |
|---|---|
| F8 (กดค้าง) | แสดงต้นฉบับ |
| Ctrl+F8 | หยุด / เริ่มการแปล |
| F9 | แปลทั้งหน้าจอ (เมนู คำอธิบายไอเทม) กดอีกครั้งหรือกด Esc เพื่อปิด |
| F10 | ตั้งกรอบข้อความ |
| F7 | ประวัติการแปล และปุ่มสร้าง glossary ชื่อตัวละคร |

- **เมนูและภารกิจ:** เปิดการตั้งค่า "แปลเมนูและภารกิจโดยอัตโนมัติเมื่อหน้าจอนิ่ง" โปรแกรมจะแปลทั้งหน้าจอเมื่อข้อความบนจอหยุดนิ่ง
  (ตัวละครที่ขยับในเมนูไม่มีผล) และแปลใหม่เมื่อข้อความบางส่วนเปลี่ยน ระหว่างที่มีบทพูด โปรแกรมจะรอนานขึ้นเพื่อไม่ให้บทพูดแปลช้า
  หากต้องการทันทีให้กด F9
- **ตัวเลือกคำตอบ:** แปลแยกทีละข้อและแสดงทับกล่องของแต่ละข้อ
- **คำลงท้าย ครับ/ค่ะ:** ปรับตามเพศของผู้พูด (จากชื่อตัวละครใน glossary) บทพูดของตัวเอกและตัวเลือกคำตอบไม่มีคำลงท้าย
  (`player_gender` ในไฟล์ profile: `neutral` / `male` / `female`)
- **แก้คำแปลที่ผิด:** กด F7 (หรือปุ่ม "ประวัติการแปล") แล้วกด ✎ ท้ายคำแปลที่ผิด เหลือไว้เฉพาะคำหรือชื่อที่ต้องการแก้
  (หรือทั้งบรรทัด) ใส่คำแปลที่ถูก แล้วเลือกว่าเป็นคำทั่วไปหรือชื่อตัวละคร (ระบุเพศเพื่อใช้คำลงท้าย ครับ/ค่ะ)
  โปรแกรมบันทึกลง `glossaries/<series>.<ภาษา>.json` และแปลหน้าจอที่แสดงอยู่ใหม่ทันที ข้อความเมนูก็อยู่ในประวัติด้วย
- **ขนาดตัวอักษรและแบบอักษร:** เปลี่ยนได้ในหน้าต่าง game-lens หัวข้อ "การแสดงผล" (มีตัวอย่างข้อความให้ดู) มีผลทันทีกับคำแปลที่แสดงอยู่ และจำแยกตามเกม
  (รายการแบบอักษรแสดงเฉพาะแบบที่มีตัวอักษรของภาษาที่แปล)
  โปรแกรมมีแบบอักษรไทยมาให้ 5 แบบในโฟลเดอร์ `fonts/` โดยไม่ต้องติดตั้งลง Windows: **Noto Sans Thai Looped** และ **Sarabun**
  (มีหัว อ่านบทพูดง่าย), **Kanit** (ไม่มีหัว แบบเกมแปลไทยทางการ), **Mitr** (ปลายมน โทนแฟนตาซี น่ารัก)
  และ **Bai Jamjuree** (เหลี่ยมนิด ๆ โทนไซไฟ) ทั้งหมดใช้สัญญาอนุญาต SIL Open Font License
  (แจกจ่ายต่อได้ฟรี ไฟล์ `OFL.txt` อยู่ในโฟลเดอร์ของแต่ละแบบ) วางไฟล์ .ttf / .otf เพิ่มในโฟลเดอร์นี้ได้
- จุดสามจุดที่มุมกรอบ = กำลังแปล
- ข้อความสั้นด้านบนหน้าจอเกม = สถานะหรือปัญหา (ปิดได้ในหน้าต่าง game-lens)
- ปิดหน้าต่าง game-lens ได้ โปรแกรมยังทำงานอยู่ที่ไอคอน 訳 มุมขวาล่างของหน้าจอ คลิกไอคอนเพื่อเปิดหน้าต่างอีกครั้ง
- แก้ไขปุ่มลัดได้ใน `settings.json`

## หลายเกม หลายภาษา

- เลือกภาษาของเกมที่ช่อง **ภาษาในเกม**: ญี่ปุ่น เกาหลี จีนตัวย่อ จีนตัวเต็ม (ไต้หวัน / ฮ่องกง) อังกฤษ
- แต่ละเกมมีโปรไฟล์ของตัวเองในโฟลเดอร์ `profiles\` (กรอบข้อความ ภาษา การตั้งค่าตัวเอก)
  เมื่อกด **เลือกเกม** เป็นเกมใหม่ โปรแกรมจะสร้างโปรไฟล์ใหม่และเดาภาษาจากชื่อหน้าต่างเกม โดยไม่แก้ไขโปรไฟล์ของเกมเดิม
- เมื่อเปิดเกมใด game-lens จะสลับไปใช้โปรไฟล์ของเกมนั้นโดยอัตโนมัติ
- การทดสอบกับเกมจริงทำกับภาษาญี่ปุ่นแล้ว ส่วนภาษาเกาหลีและจีนทดสอบกับภาพที่จำลองบทพูดในลักษณะเดียวกับเกม

## เครื่องแปล

เลือกได้ในหน้าต่าง game-lens เครื่องแปลที่ต้องใช้ key ให้วาง key ในช่องแล้วกด **บันทึก key** โปรแกรมจะทดสอบให้ทันที

| เครื่องแปล | หมายเหตุ |
|---|---|
| โมเดลแปลภาษาในเครื่อง (ค่าเริ่มต้น) | ฟรี ไม่ต้องใช้อินเทอร์เน็ต เลือกรุ่นตามการ์ดจอ (ดูด้านล่าง) |
| Google ฟรี | ไม่ต้องสมัคร ไม่ใช้การ์ดจอ (ช่องทางไม่เป็นทางการ อาจใช้งานไม่ได้โดยไม่แจ้งล่วงหน้า) |
| DeepL | ฟรี 500,000 ตัวอักษรต่อเดือน (สมัคร DeepL API Free) |
| Microsoft Azure | ฟรี 2,000,000 ตัวอักษรต่อเดือน (แผน F0) |
| Google Cloud | ฟรี 500,000 ตัวอักษรต่อเดือน |
| Claude | คุณภาพสูงที่สุด คิดค่าบริการตามการใช้งาน |

**รุ่นของโมเดลในเครื่อง** (ช่อง **รุ่นโมเดล** ค่าเริ่มต้นเป็นอัตโนมัติ):

| การ์ดจอ | รุ่นที่ใช้ | ความเร็วโดยประมาณ | หน่วยความจำการ์ดจอ | ดาวน์โหลด |
|---|---|---|---|---|
| 10 GB ขึ้นไป | Index-Translate 9B (แปลเป็นธรรมชาติที่สุดในการทดสอบ) | ~0.6 วินาทีต่อประโยค | ~5.5 GB | 5.8 GB |
| น้อยกว่า 10 GB | Hy-MT2 1.8B | ~0.3 วินาทีต่อประโยค | ~2 GB | 1.1 GB |
| ไม่มีการ์ดจอแยก | Hy-MT2 1.8B บน CPU | ~0.8–2 วินาทีต่อประโยค | — | 1.1 GB |

เลือก Hy-MT2 7B ได้เช่นกัน เมื่อเปลี่ยนรุ่น โปรแกรมจะสลับให้ทันที และดาวน์โหลดรุ่นที่ยังไม่มีโดยอัตโนมัติ

- key ถูกเก็บไว้ในเครื่องนี้เท่านั้น ที่ `server/data/keys.json`
- หากเครื่องแปลออนไลน์ใช้งานไม่ได้ โปรแกรมจะเปลี่ยนไปใช้โมเดลในเครื่องที่เปิดอยู่
- ประโยคที่เคยแปลแล้วจะแสดงทันทีจาก cache โดยไม่ใช้โควตาซ้ำ
- **glossary** (ชื่อตัวละครและคำศัพท์) ของแต่ละเกมอยู่ที่ `glossaries/<series>.<ภาษา>.json` ชื่อใน glossary แปลเหมือนกันทุกเครื่องแปล
  และช่อง `gender` ใช้ปรับคำลงท้าย ครับ/ค่ะ ของ Azur Promilia อยู่ที่ `glossaries/azur-promilia.th.json`
  (ชื่อเขียนเป็นอักษรโรมันตามเว็บไซต์ทางการภาษาไทย ช่อง `source` ระบุว่ามาจากเว็บไซต์ทางการ (`official`) หรือเว็บไซต์ของแฟน (`fan`))
  เมื่อแปลเป็นภาษาอังกฤษจะใช้ `glossaries/azur-promilia.en.json` แทน (ชื่อสถานที่ส่วนใหญ่ยังไม่มีชื่อภาษาอังกฤษทางการ
  จึงสะกดตามเว็บไซต์ทางการภาษาไทยหรือแปลตามความหมาย) เปลี่ยนภาษาที่แปลแล้วโปรแกรมจะส่งรายการของภาษานั้นให้ทันที

## การแก้ไขปัญหา

- **แปลช้า:** ตรวจสอบด้วย `nvidia-smi` ว่ามีโปรแกรมอื่น (เช่น ComfyUI) ใช้การ์ดจออยู่หรือไม่ โมเดลในเครื่องจะช้าลงหลายเท่า
  โปรดปิดโปรแกรมนั้น หรือเลือกรุ่นโมเดลที่เล็กลง หรือใช้เครื่องแปลออนไลน์
- **คำแปลแสดงก่อนประโยคจบ:** เป็นการทำงานปกติ โปรแกรมแสดงคำแปลท่อนแรกก่อน แล้วเปลี่ยนเป็นคำแปลเต็มเมื่อเกมแสดงข้อความต่อ
- **บทพูดบรรทัดที่ 3 ไม่ถูกแปล:** กด F10 แล้วลากขอบล่างของกรอบบทพูดให้ครอบ 3 บรรทัด
- **กดข้ามบทพูดเร็ว (ไม่ถึงประมาณ 2 วินาที) แล้วไม่มีคำแปล:** การแปลใช้เวลา 1–2 วินาทีหลังข้อความแสดงครบ บรรทัดที่ถูกข้ามก่อนหน้านั้นจะไม่แสดงคำแปล
- **ป้ายปุ่มในเกมแสดงเป็นรูปสี่เหลี่ยม □:** เกิดจากแป้นพิมพ์ภาษาไทย การตั้งค่า "เปลี่ยนแป้นพิมพ์เป็นภาษาอังกฤษโดยอัตโนมัติขณะอยู่ในเกม"
  จะเปลี่ยนให้ หากการตั้งค่านี้เป็นสีเทา แสดงว่าเกมทำงานในสิทธิ์ผู้ดูแลระบบ (เช่น Azur Promilia) ซึ่ง Windows ไม่อนุญาต
  ให้ตั้งค่า Windows ครั้งเดียวแทน: Settings > Time & Language > Language > Keyboard (Advanced keyboard settings)
  เลือก **Override for default input method** เป็น English แล้วติ๊ก **Let me use a different input method for each app window**
  จากนั้นปิดและเปิดเกมใหม่
- **Google ฟรีแจ้ง 429:** ถูกจำกัดการใช้งานชั่วคราว โปรดใช้เครื่องแปลอื่น
- **ขอบสีเหลืองรอบหน้าต่างเกม:** เกิดจาก Windows 10 ขณะจับภาพหน้าต่าง ไม่สามารถปิดได้ (Windows 11 ไม่มีขอบนี้)
- **รายละเอียดข้อผิดพลาด:** `logs/gamelens.log` และ `logs/server.log`

ทดสอบกับวิดีโอที่บันทึกจากเกม: `tools\replay_video.py` เล่นคลิปผ่านระบบจับบทพูดจริง แล้วรายงานจำนวนบรรทัดที่แปลได้และความเร็ว

## โครงสร้าง

- `gamelens/` ตัวแอป (หน้าต่าง การจับภาพ การแสดงทับ การติดตามบทพูด) ข้อความของหน้าต่างทั้งสองภาษาอยู่ใน `gamelens/i18n.py`
- `server/` ระบบอ่านข้อความ (PP-OCR) และแปลภาษา ทำงานที่ `127.0.0.1:9960` แอปเปิดและปิดให้เอง
- `profiles/` โปรไฟล์ของแต่ละเกม, `glossaries/` ชื่อตัวละครและคำศัพท์
- โมเดลแปลภาษาอยู่ที่ `models_dir` ใน `settings.json` (ชุด portable ใช้โฟลเดอร์ `models\` ของโปรแกรม)
- `server/data/` cache คำแปล glossary และ key (อยู่ในเครื่องนี้เท่านั้น)
