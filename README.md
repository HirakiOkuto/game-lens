# game-lens — โปรแกรมแปลข้อความในเกมแบบเรียลไทม์และแสดงผลทับบนหน้าจอเกม

game-lens อ่านข้อความในเกม ได้แก่ บทพูด ชื่อผู้พูด ตัวเลือกคำตอบ และเมนู แล้วแสดงคำแปลทับตำแหน่งของข้อความเดิมบนหน้าจอเกม
โปรแกรมรองรับเกมภาษาญี่ปุ่น เกาหลี จีนตัวย่อ จีนตัวเต็ม และอังกฤษ โดยแปลเป็นภาษาไทยหรือภาษาอังกฤษ

โปรแกรมไม่แก้ไขไฟล์ของเกม ไม่อ่านหน่วยความจำของเกม และไม่แทรกโค้ดเข้าสู่เกม การทำงานอาศัยเพียงการจับภาพหน้าต่างเกม
(Windows Graphics Capture ซึ่งเป็นวิธีเดียวกับโปรแกรมบันทึกหน้าจอ) และหน้าต่างโปร่งใสที่วางทับหน้าต่างเกมโดยไม่รับการคลิก

หน้าต่างของโปรแกรมแสดงผลได้ทั้งภาษาอังกฤษ (ค่าเริ่มต้น) และภาษาไทย ผู้ใช้สามารถเปลี่ยนภาษาได้ที่มุมขวาบนของหน้าต่าง

## ความต้องการของระบบ

- Windows 10 หรือ Windows 11 และการเชื่อมต่ออินเทอร์เน็ตสำหรับการเปิดใช้งานครั้งแรก
- เกมต้องแสดงผลแบบ **Borderless** หรือ **Windowed** (โปรแกรมไม่สามารถแสดงผลทับโหมด Exclusive Fullscreen ได้)
- โมเดลแปลภาษาในเครื่องใช้งานได้ทั้งในเครื่องที่มีและไม่มีการ์ดแสดงผล โดยโปรแกรมเลือกรุ่นตามหน่วยความจำของการ์ดแสดงผล
  (ดูหัวข้อ "ระบบแปลภาษา")
- ระบบอ่านข้อความ (OCR) ใช้การ์ดแสดงผลที่รองรับ DirectX 12 ทุกยี่ห้อ หากใช้งานไม่ได้ โปรแกรมจะเปลี่ยนไปใช้หน่วยประมวลผลกลาง (CPU) โดยอัตโนมัติ

## การติดตั้ง

### ชุดพร้อมใช้งาน (portable) — แนะนำ

1. แตกไฟล์ `game-lens-portable-<วันที่>.zip` ไว้ในโฟลเดอร์ที่สามารถเขียนไฟล์ได้ เช่น `D:\game-lens`
   (ไม่ควรเก็บไว้ใน Program Files)
2. ดับเบิลคลิกไฟล์ **game-lens.exe**
3. หาก Windows แสดงข้อความ "Windows protected your PC" ให้คลิก **More info** แล้วคลิก **Run anyway**
   (เนื่องจากโปรแกรมไม่มีลายเซ็นดิจิทัล)

ชุดพร้อมใช้งาน (ไฟล์ zip ขนาดประมาณ 150 MB และประมาณ 410 MB เมื่อแตกไฟล์) ประกอบด้วย Python ส่วนประกอบที่จำเป็นทั้งหมด
แบบอักษรภาษาไทย และ llama.cpp รุ่น Vulkan ซึ่งใช้ได้กับการ์ดแสดงผลทุกยี่ห้อ จึงไม่จำเป็นต้องติดตั้งสิ่งใดเพิ่มเติม
เมื่อเปิดใช้งานครั้งแรก โปรแกรมจะดาวน์โหลดไฟล์ต่อไปนี้โดยอัตโนมัติ และแสดงความคืบหน้าในหน้าต่าง game-lens

| ไฟล์ | ขนาด | ดาวน์โหลดเมื่อ |
|---|---|---|
| ระบบอ่านข้อความ (ภาษาญี่ปุ่น จีน และอังกฤษ) | ประมาณ 87 MB | เปิดใช้งานครั้งแรก |
| ระบบอ่านข้อความภาษาเกาหลี | ประมาณ 18 MB | เลือกเกมภาษาเกาหลีครั้งแรก |
| โมเดลแปลภาษา | 1.1–5.8 GB ตามรุ่น | ใช้โมเดลแปลภาษาในเครื่องครั้งแรก |

หากการดาวน์โหลดหยุดลงก่อนเสร็จสิ้น ให้เปิดโปรแกรมอีกครั้ง โปรแกรมจะดาวน์โหลดต่อจากส่วนที่ค้างอยู่

### การติดตั้งจากซอร์สโค้ด

1. ติดตั้ง [Python 3.14](https://www.python.org/downloads/)
2. แตกไฟล์ `game-lens-<วันที่>.zip` แล้วดับเบิลคลิกไฟล์ **setup.bat**
3. หาก setup แจ้งว่าไม่พบคำสั่ง `llama` และผู้ใช้ต้องการใช้โมเดลแปลภาษาในเครื่อง ให้ติดตั้ง
   [Llama for Windows](https://github.com/ggml-org/Llama-Windows/releases) (ไฟล์ `.msixbundle` รุ่นล่าสุด)
4. ดับเบิลคลิกไฟล์ **start.bat** เพื่อเปิดโปรแกรม

### ไอคอนบนเดสก์ท็อป

คลิกปุ่ม **Desktop icon / สร้างไอคอนบนเดสก์ท็อป** ในหน้าต่าง game-lens หลังจากนั้นผู้ใช้สามารถเปิดโปรแกรมได้โดยดับเบิลคลิกไอคอน game-lens
โปรแกรมจะเปิดระบบแปลภาษาและโมเดลโดยอัตโนมัติ และปิดระบบดังกล่าวเมื่อผู้ใช้เลือก **Quit / ปิดโปรแกรม**

## การตั้งค่าครั้งแรก (3 ขั้นตอน)

หน้าต่าง game-lens แสดงสถานะของแต่ละขั้นตอน (จุดสีเขียวหมายถึงพร้อมใช้งาน) พร้อมปุ่มสำหรับขั้นตอนที่ยังไม่เสร็จสิ้น

1. **ระบบแปลภาษา** — โปรแกรมเปิดระบบโดยอัตโนมัติ กรุณารอจนกว่าสถานะจะแสดงว่า "พร้อมใช้งาน"
2. **เกม** — คลิก **เลือกเกม** แล้วเลือกจากรายการ หรือคลิก **ตรวจจับอัตโนมัติ** แล้วสลับไปยังหน้าต่างเกมภายใน 5 วินาที
3. **กรอบข้อความ** — ไปยังหน้าที่มีบทพูดในเกม แล้วคลิก **ตั้งกรอบ** (หรือกดปุ่ม F10)
   - โปรแกรมจะค้นหาข้อความบนหน้าจอและแสดงเส้นประ ให้คลิกที่บทพูดหนึ่งครั้งเพื่อสร้างกรอบ แล้วคลิกที่ชื่อผู้พูด
   - ลากในพื้นที่ว่าง: สร้างกรอบใหม่ • ลากกรอบ: ย้ายกรอบ • ลากมุมขวาล่าง: ปรับขนาด
   - กดปุ่ม 1 / 2 / 3 / 4: กำหนดเป็นบทพูด / ชื่อผู้พูด / คำบรรยาย / ตัวเลือกคำตอบ • Delete: ลบ • Enter: บันทึก
   - คลิกขวาที่กรอบเพื่อเลือกสีตัวอักษร (ตัวอักษรสีเข้มบนพื้นสีอ่อน) หรือจัดข้อความกึ่งกลาง
   - รองรับบทพูดที่แสดงกลางจอทับฉากเกมโดยไม่มีกล่องข้อความ ทั้งนี้ กรอบบทพูดควรมีขนาดพอสำหรับ 3 บรรทัด

เมื่อดำเนินการครบทั้ง 3 ขั้นตอน โปรแกรมจะเริ่มแปลโดยอัตโนมัติและจดจำการตั้งค่าไว้ ในการใช้งานครั้งต่อไป ผู้ใช้เพียงเปิดเกมเท่านั้น
(ทั้ง 3 ขั้นตอนจะย่อเหลือบรรทัดเดียว คลิก **รายละเอียด** เพื่อดูหรือแก้ไขอีกครั้ง)
โปรไฟล์ของ Azur Promilia มีกรอบข้อความที่กำหนดไว้แล้ว (วัดจากเกมรุ่นทดสอบ CBT ที่สัดส่วนจอ 16:9)

## การใช้งานระหว่างเล่นเกม

| ปุ่ม | การทำงาน |
|---|---|
| F8 (กดค้าง) | แสดงข้อความต้นฉบับ |
| Ctrl+F8 | หยุดหรือเริ่มการแปล |
| F9 | แปลทั้งหน้าจอ (เช่น เมนูและคำอธิบายไอเทม) กดอีกครั้งหรือกด Esc เพื่อปิด |
| F10 | ตั้งกรอบข้อความ |
| F7 | เปิดประวัติการแปล แก้ไขคำแปล และสร้างรายการชื่อตัวละคร |

- **เมนูและภารกิจ:** เมื่อเปิดการตั้งค่า "แปลเมนูและภารกิจโดยอัตโนมัติเมื่อหน้าจอนิ่ง" โปรแกรมจะแปลทั้งหน้าจอเมื่อข้อความบนจอหยุดนิ่ง
  (การเคลื่อนไหวของตัวละครในเมนูไม่มีผลต่อการทำงาน) ระหว่างที่มีบทพูด โปรแกรมจะรอนานขึ้นเพื่อไม่ให้การแปลบทพูดล่าช้า
  หากต้องการแปลทันที ให้กดปุ่ม F9
  - คำแปลของเมนูจะแสดงทีละส่วนจากบนลงล่าง (ส่วนแรกภายในประมาณ 1 วินาที) ส่วนเมนูที่เคยแปลแล้วจะแสดงเกือบทันที
  - เมื่อมีหน้าต่างป๊อปอัปหรือมีการสลับแท็บ โปรแกรมจะนำออกเฉพาะคำแปลของข้อความที่เปลี่ยนไปหรือถูกบัง แล้วแปลข้อความใหม่
    คำแปลส่วนอื่นยังคงแสดงอยู่
  - ข้อความที่แตกต่างจากข้อความที่เคยแปลเฉพาะตัวเลข (เช่น "Lv.3" และ "Lv.12") จะใช้คำแปลเดิมโดยเปลี่ยนเฉพาะตัวเลข
  - ข้อความที่เกมแสดงในแนวเอียง (เช่น หัวข้อในสมุดผลงาน) คำแปลจะแสดงในแนวเอียงเดียวกัน
  - คำแปลที่ยาวกว่าต้นฉบับจะแสดงภายในแผงหรือปุ่มของข้อความนั้น หากพื้นที่ไม่เพียงพอ โปรแกรมจะลดขนาดตัวอักษรหรือขึ้นบรรทัดใหม่
    โดยไม่ทับคำแปลข้างเคียง
  - ข้อความสีอ่อนขนาดเล็กที่วางบนฉากเกมโดยตรง (เช่น ป้ายในโหมดถ่ายภาพ) โปรแกรมจะอ่านซ้ำอย่างละเอียดเมื่อหน้าจอมีรายละเอียดมาก
    และพบข้อความน้อย ซึ่งใช้เวลาเพิ่มประมาณ 0.8 วินาที
- **ตัวเลือกคำตอบ:** แปลแยกทีละข้อและแสดงทับกล่องของแต่ละข้อ
- **คำลงท้าย ครับ/ค่ะ:** ปรับตามเพศของผู้พูดตามข้อมูลในรายการชื่อตัวละคร บทพูดของตัวเอกและตัวเลือกคำตอบจะไม่มีคำลงท้าย
  (กำหนดได้ที่ `player_gender` ในไฟล์โปรไฟล์: `neutral` / `male` / `female`)
- **การแก้ไขคำแปล:** กดปุ่ม F7 (หรือคลิกปุ่ม "ประวัติการแปล") แล้วคลิก ✎ ท้ายคำแปลที่ต้องการแก้ไข ระบุเฉพาะคำหรือชื่อที่ต้องการแก้
  (หรือทั้งบรรทัด) พร้อมคำแปลที่ถูกต้อง แล้วเลือกว่าเป็นคำทั่วไปหรือชื่อตัวละคร (สำหรับชื่อตัวละคร ให้ระบุเพศเพื่อใช้กำหนดคำลงท้าย)
  โปรแกรมจะบันทึกลงไฟล์ `glossaries/<series>.<ภาษา>.json` และแปลหน้าจอที่แสดงอยู่ใหม่ทันที ข้อความในเมนูจะปรากฏในประวัติด้วยเช่นกัน
- **ขนาดตัวอักษรและแบบอักษร:** ปรับได้ในหน้าต่าง game-lens หัวข้อ "การแสดงผล" (มีตัวอย่างข้อความประกอบ)
  การปรับจะมีผลกับคำแปลที่แสดงอยู่ทันที และจัดเก็บแยกตามเกม (รายการแบบอักษรแสดงเฉพาะแบบที่มีตัวอักษรของภาษาที่แปล)
  โปรแกรมมีแบบอักษรภาษาไทย 5 แบบในโฟลเดอร์ `fonts/` ซึ่งใช้งานได้โดยไม่ต้องติดตั้งลงใน Windows ได้แก่
  **Noto Sans Thai Looped** และ **Sarabun** (แบบมีหัว อ่านบทพูดได้ง่าย), **Kanit** (แบบไม่มีหัว ลักษณะเดียวกับเกมแปลไทยอย่างเป็นทางการ),
  **Mitr** (ปลายมน เหมาะกับเกมแนวแฟนตาซี) และ **Bai Jamjuree** (ทรงเหลี่ยม เหมาะกับเกมแนววิทยาศาสตร์) ทุกแบบใช้สัญญาอนุญาต
  SIL Open Font License ซึ่งอนุญาตให้เผยแพร่ซ้ำได้โดยไม่มีค่าใช้จ่าย (ไฟล์ `OFL.txt` อยู่ในโฟลเดอร์ของแต่ละแบบ)
  ผู้ใช้สามารถเพิ่มไฟล์ .ttf หรือ .otf ลงในโฟลเดอร์นี้ได้
- จุดสามจุดที่มุมกรอบหมายถึงโปรแกรมกำลังแปล
- ข้อความสั้นที่ด้านบนของหน้าจอเกมแสดงสถานะหรือปัญหาที่พบ (ปิดได้ในหน้าต่าง game-lens)
- เมื่อปิดหน้าต่าง game-lens โปรแกรมยังคงทำงานอยู่ที่ไอคอน 訳 มุมขวาล่างของหน้าจอ คลิกที่ไอคอนเพื่อเปิดหน้าต่างอีกครั้ง
- ผู้ใช้สามารถเปลี่ยนปุ่มลัดได้ในหน้าต่าง game-lens โดยคลิกปุ่ม "ปุ่มลัด" ด้านล่าง คลิกที่ปุ่มลัดที่ต้องการเปลี่ยน แล้วกดปุ่มใหม่
  (ปุ่มตัวอักษรต้องใช้ร่วมกับ Ctrl หรือ Alt เนื่องจากเกมใช้ปุ่มเหล่านั้น)

## การใช้งานกับหลายเกมและหลายภาษา

- เลือกภาษาของเกมที่ช่อง **ภาษาในเกม** ได้แก่ ญี่ปุ่น เกาหลี จีนตัวย่อ จีนตัวเต็ม (ไต้หวัน / ฮ่องกง) และอังกฤษ
  และเลือกภาษาปลายทางที่ช่อง **แปลเป็น** ได้แก่ ไทย หรืออังกฤษ (หัวข้อ "ภาษา" ในหน้าต่าง game-lens)
- เกมแต่ละเกมมีโปรไฟล์ของตนเองในโฟลเดอร์ `profiles\` (กรอบข้อความ ภาษา และการตั้งค่าตัวเอก)
  เมื่อเลือกเกมใหม่ผ่านปุ่ม **เลือกเกม** โปรแกรมจะสร้างโปรไฟล์ใหม่และคาดคะเนภาษาจากชื่อหน้าต่างเกม โดยไม่แก้ไขโปรไฟล์ของเกมอื่น
- เมื่อผู้ใช้เปิดเกมใด game-lens จะสลับไปใช้โปรไฟล์ของเกมนั้นโดยอัตโนมัติ
- การทดสอบกับเกมจริงดำเนินการกับภาษาญี่ปุ่นแล้ว ส่วนภาษาเกาหลีและภาษาจีนทดสอบกับภาพที่จำลองบทพูดในลักษณะเดียวกับเกม

ผู้ใช้สามารถเลือกรุ่น Hy-MT2 7B ได้เช่นกัน เมื่อเปลี่ยนรุ่น โปรแกรมจะสลับรุ่นทันทีและดาวน์โหลดรุ่นที่ยังไม่มีโดยอัตโนมัติ

- คีย์ทั้งหมดจัดเก็บไว้ในเครื่องของผู้ใช้เท่านั้น ที่ไฟล์ `server/data/keys.json`
- หากระบบแปลภาษาออนไลน์ใช้งานไม่ได้ โปรแกรมจะเปลี่ยนไปใช้โมเดลในเครื่องที่เปิดอยู่
- ประโยคที่เคยแปลแล้วจะแสดงทันทีจากแคช (cache) โดยไม่ใช้โควตาซ้ำ
- เมื่อเปิดโปรแกรม ระบบจะโหลดระบบอ่านข้อความและเรียกใช้โมเดลหนึ่งครั้งล่วงหน้า เพื่อให้เมนูแรกและบทพูดแรกแสดงผลได้ตามปกติ
- **รายการชื่อตัวละครและคำศัพท์ (glossary)** ของแต่ละเกมอยู่ที่ `glossaries/<series>.<ภาษา>.json` ชื่อในรายการจะแปลเหมือนกันทุกระบบแปลภาษา
  และช่อง `gender` ใช้กำหนดคำลงท้าย ครับ/ค่ะ รายการของ Azur Promilia อยู่ที่ `glossaries/azur-promilia.th.json`
  (ชื่อเขียนด้วยอักษรโรมันตามเว็บไซต์ทางการภาษาไทย ช่อง `source` ระบุแหล่งที่มา ได้แก่ เว็บไซต์ทางการ (`official`)
  หรือเว็บไซต์ของผู้เล่น (`fan`))
  เมื่อแปลเป็นภาษาอังกฤษ โปรแกรมจะใช้ `glossaries/azur-promilia.en.json` แทน (ชื่อสถานที่ส่วนใหญ่ยังไม่มีชื่อภาษาอังกฤษอย่างเป็นทางการ
  จึงสะกดตามเว็บไซต์ทางการภาษาไทยหรือแปลตามความหมาย) เมื่อเปลี่ยนภาษาปลายทาง โปรแกรมจะใช้รายการของภาษานั้นทันที
- **ชื่อผู้พูดที่ไม่อยู่ในรายการ:** หากช่องชื่อผู้พูดพบชื่อภาษาญี่ปุ่นที่เขียนด้วยอักษรคาตากานะซึ่งไม่อยู่ในรายการ โปรแกรมจะขอชื่อภาษาอังกฤษจากระบบแปลภาษาหนึ่งครั้ง
  ตรวจสอบว่ามีลักษณะเป็นชื่อเฉพาะ แล้วจดจำไว้ใช้กับทั้งช่องชื่อผู้พูดและบทพูดต่อจากนั้น ชื่อดังกล่าวจึงสะกดเหมือนกันทุกครั้ง
  หากการสะกดไม่ถูกต้อง ผู้ใช้สามารถแก้ไขได้ในประวัติการแปล (F7) โดยชื่อที่ผู้ใช้แก้ไขจะมีลำดับความสำคัญสูงกว่าเสมอ

## การแก้ไขปัญหา

- **การแปลล่าช้า:** ตรวจสอบด้วยคำสั่ง `nvidia-smi` ว่ามีโปรแกรมอื่น (เช่น ComfyUI) ใช้การ์ดแสดงผลอยู่หรือไม่ ซึ่งทำให้โมเดลในเครื่องทำงานช้าลงหลายเท่า
  กรุณาปิดโปรแกรมดังกล่าว เลือกรุ่นโมเดลที่เล็กลง หรือใช้ระบบแปลภาษาออนไลน์
- **คำแปลแสดงก่อนประโยคจบ:** เป็นการทำงานตามปกติ โปรแกรมแสดงคำแปลของส่วนแรกก่อน แล้วเปลี่ยนเป็นคำแปลฉบับเต็มเมื่อเกมแสดงข้อความต่อ
- **บทพูดบรรทัดที่ 3 ไม่ถูกแปล:** กดปุ่ม F10 แล้วลากขอบล่างของกรอบบทพูดให้ครอบคลุม 3 บรรทัด
- **ข้ามบทพูดอย่างรวดเร็ว (น้อยกว่าประมาณ 2 วินาที) แล้วไม่มีคำแปล:** การแปลใช้เวลา 1–2 วินาทีหลังจากข้อความแสดงครบ
  บรรทัดที่ถูกข้ามก่อนหน้านั้นจะไม่มีคำแปลแสดง
- **ป้ายปุ่มในเกมแสดงเป็นรูปสี่เหลี่ยม □:** เกิดจากแป้นพิมพ์ภาษาไทย การตั้งค่า "เปลี่ยนแป้นพิมพ์เป็นภาษาอังกฤษโดยอัตโนมัติขณะอยู่ในเกม"
  จะแก้ไขปัญหานี้ หากการตั้งค่าดังกล่าวเป็นสีเทา แสดงว่าเกมทำงานด้วยสิทธิ์ผู้ดูแลระบบ (เช่น Azur Promilia) ซึ่ง Windows ไม่อนุญาตให้เปลี่ยน
  (ใต้การตั้งค่ามีปุ่มสำหรับเปิดการตั้งค่าแป้นพิมพ์ของ Windows)
  ในกรณีนี้ ให้ตั้งค่า Windows หนึ่งครั้งแทน ดังนี้ Settings > Time & Language > Language > Keyboard (Advanced keyboard settings)
  เลือก **Override for default input method** เป็น English แล้วเลือก **Let me use a different input method for each app window**
  จากนั้นปิดและเปิดเกมใหม่
- **เมนูบางหน้าไม่ถูกแปลหรือแปลไม่ครบ:** กดปุ่ม F9 เพื่อแปลหน้านั้นทันที (กดอีกครั้งเพื่อปิด) หากปัญหาเกิดกับหน้าเดิมซ้ำ
  กรุณาเก็บภาพหน้าจอและไฟล์ `logs/gamelens.log` ไว้ประกอบการตรวจสอบ
- **Google ฟรีแจ้งรหัส 429:** บริการจำกัดการใช้งานชั่วคราว กรุณาใช้ระบบแปลภาษาอื่น
- **ระบบอ่านข้อความบนการ์ดแสดงผล (DirectML):** อ่านทั้งหน้าจอได้ภายในประมาณ 0.3–0.5 วินาที หากการ์ดแสดงผลใช้งานไม่ได้
  โปรแกรมจะเปลี่ยนไปใช้ CPU โดยอัตโนมัติ (ไฟล์ `logs/server.log` จะบันทึกว่า "text reader … on DmlExecutionProvider")
  หากเกมกระตุกขณะแปลเมนู ให้ตั้งค่าตัวแปรสภาพแวดล้อม `OCR_GPU=0` ก่อนเปิด game-lens เพื่อให้อ่านข้อความด้วย CPU
- **ขอบสีเหลืองรอบหน้าต่างเกม:** เกิดจาก Windows 10 ขณะจับภาพหน้าต่าง และไม่สามารถปิดได้ (Windows 11 ไม่มีขอบนี้)
- **รายละเอียดข้อผิดพลาด:** ดูได้ที่ไฟล์ `logs/gamelens.log` และ `logs/server.log`

ชุดที่สร้างขึ้นมีระบบแปล "Google ฟรี" ซึ่งใช้ช่องทางที่ไม่เป็นทางการของ Google ร่วมกับคีย์ที่ฝังอยู่ใน Chrome
หากต้องการชุดที่ไม่มีระบบแปลนี้ ให้เพิ่มตัวเลือก `--no-google-free` โปรแกรมจะตัดคีย์ออกจากโค้ดและซ่อนระบบแปลดังกล่าว
(ไฟล์ `PUBLIC_BUILD` ดูรายละเอียดใน `tools/public.py`) และชื่อไฟล์จะมีคำว่า `nogoogle`

ไลบรารีที่ใช้อยู่ในไฟล์ `requirements.txt` ระบบอ่านข้อความใช้ `onnxruntime-directml` (มิใช่ `onnxruntime` รุ่นปกติ และห้ามติดตั้งทั้งสองรุ่นพร้อมกัน)
ตัวแปรสภาพแวดล้อม: `OCR_GPU=0` (อ่านข้อความด้วย CPU), `OCR_THREADS` (จำนวนเธรดเมื่อใช้ CPU), `GAMELENS_PROFILE` (โปรไฟล์ที่ใช้)

## โครงสร้างของโปรแกรม

- `gamelens/` ตัวแอปพลิเคชัน (หน้าต่าง การจับภาพ การแสดงผลทับ และการติดตามบทพูด) ข้อความของหน้าต่างทั้งสองภาษาอยู่ใน `gamelens/i18n.py`
- `server/` ระบบอ่านข้อความ (PP-OCR) และระบบแปลภาษา ทำงานที่ `127.0.0.1:9960` แอปพลิเคชันเปิดและปิดระบบนี้โดยอัตโนมัติ
- `profiles/` โปรไฟล์ของแต่ละเกม, `glossaries/` รายการชื่อตัวละครและคำศัพท์, `fonts/` แบบอักษรที่มาพร้อมโปรแกรม
- `tools/` เครื่องมือสำหรับการทดสอบและการสร้างชุดเผยแพร่, `tests/` และ `server/tests/` ชุดทดสอบ
- `licenses/` สัญญาอนุญาตของซอฟต์แวร์อื่นที่โปรแกรมใช้ (รายละเอียดใน [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md))
- ต้นแบบเซิร์ฟเวอร์ภาษา Rust ที่จัดทำขึ้นเพื่อวัดผลเปรียบเทียบได้นำออกจากโปรเจกต์แล้ว เนื่องจากไม่ได้ทำให้การแปลเร็วขึ้น สามารถเรียกดูได้จาก tag `experiment/rust-server`
- โมเดลแปลภาษาอยู่ที่ตำแหน่ง `models_dir` ในไฟล์ `settings.json` (ค่าเริ่มต้นคือโฟลเดอร์ `models\` ของโปรแกรม)
  ไฟล์ `settings.json` เป็นการตั้งค่าของเครื่องแต่ละเครื่อง โปรแกรมสร้างขึ้นเมื่อเปิดใช้งานครั้งแรก และไม่รวมอยู่ในโปรเจกต์
- `server/data/` แคชคำแปล รายการคำศัพท์ และคีย์ (จัดเก็บไว้ในเครื่องของผู้ใช้เท่านั้น)
