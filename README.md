# game-lens — แปลเกมญี่ปุ่นเป็นไทยแบบ real-time ทับข้อความในเกม

โปรแกรมอยู่ในโฟลเดอร์นี้ครบทั้งชุด (ตัวแอป + server อ่านข้อความและแปลใน `server/`) ไม่ต้องพึ่งโปรเจกต์อื่น และไม่ inject หรืออ่าน memory ของเกม
ใช้แค่การจับภาพหน้าต่าง (Windows Graphics Capture แบบเดียวกับ OBS) กับหน้าต่าง overlay โปร่งใสที่คลิกทะลุได้

## ติดตั้ง (ครั้งแรกบนเครื่องใหม่)

ต้องมี Windows 10/11 และ [Python 3.14](https://www.python.org/downloads/) โมเดลแปลในเครื่องใช้ได้ทั้งมีและไม่มีการ์ดจอ (เลือกรุ่นให้เอง ดูตารางเครื่องแปล)

1. แตกไฟล์ zip ไว้ที่ไหนก็ได้ (เช่น `D:\game-lens`)
2. ดับเบิลคลิก **setup.bat** ซึ่งจะติดตั้งส่วนประกอบ (โมเดลแปลจะดาวน์โหลดเองตอนเปิด game-lens ครั้งแรก)
3. ถ้า setup บอกว่าไม่มีคำสั่ง `llama` ให้ติดตั้ง [Llama for Windows](https://github.com/ggml-org/Llama-Windows/releases)
   (ไฟล์ `.msixbundle` ล่าสุด) ไม่ติดตั้งก็ได้ถ้าจะใช้ Google / DeepL / Azure ซึ่งไม่ใช้การ์ดจอ

## เปิดใช้งาน

ครั้งแรก: ดับเบิลคลิก **start.bat** แล้วกดปุ่ม **สร้างไอคอนบน Desktop** ในหน้าต่าง game-lens
ครั้งต่อไป: ดับเบิลคลิกไอคอน **game-lens** บน Desktop

game-lens เปิดระบบแปลกับโมเดลในเครื่องให้เอง และปิดให้เมื่อกด **ปิดโปรแกรม** ไม่ต้องเปิดหน้าต่างอื่น

## 3 ขั้นตอนในหน้าต่าง game-lens

หน้าต่างจะบอกเองว่าขั้นไหนยังไม่เสร็จ (จุดสีเขียว = พร้อม) และมีปุ่มให้กดตรงขั้นนั้น

1. **ระบบแปล** — เปิดเองอัตโนมัติ รอจนขึ้น "พร้อม"
2. **เกม** — กด **เลือกเกม** แล้วเลือกจากรายการ หรือกด **ตรวจจับอัตโนมัติ** แล้วสลับไปที่เกมภายใน 5 วินาที
   ตั้งเกมเป็น **Borderless / Windowed** เพราะ overlay ทับโหมด exclusive fullscreen ไม่ได้
3. **กรอบข้อความ** — ไปหน้าที่มีบทพูดในเกม แล้วกด **ตั้งกรอบ** (หรือ F10)
   - game-lens จะหาข้อความบนจอและตีเส้นประให้ **คลิกที่บทพูด** หนึ่งครั้งก็ได้กรอบ แล้วคลิกที่ชื่อผู้พูดอีกครั้ง
   - ลากที่ว่าง = กรอบใหม่ • ลากกรอบ = ย้าย • ลากมุมขวาล่าง = ปรับขนาด
   - กด 1 / 2 / 3 / 4 = บทพูด / ชื่อผู้พูด / ซับ / ตัวเลือกคำตอบ • Delete = ลบ • Enter = บันทึก
   - ถ้าตัวอักษรในเกมสีเข้มบนพื้นสว่าง ให้คลิกขวาที่กรอบแล้วเลือก "สีตัวอักษร: เข้ม"
   - บทพูดที่ลอยกลางจอทับฉากเกม (ไม่มีกล่อง) ก็ใช้ได้: กรอบจะถูกจัดกึ่งกลางให้เอง และกว้างพอสำหรับบรรทัดยาว

ครบสามขั้นแล้วจะเริ่มแปลเอง ค่าทั้งหมดถูกจำไว้ ครั้งต่อไปแค่เปิดเกม

## หลายเกม หลายภาษา

- เกมที่แปลได้: ญี่ปุ่น เกาหลี จีนตัวย่อ จีนตัวเต็ม (ไต้หวัน / ฮ่องกง) อังกฤษ เลือกที่ช่อง **ภาษาในเกม** ในหน้าต่าง game-lens
- แต่ละเกมมีโปรไฟล์ของตัวเองใน `profiles\` (กรอบข้อความ ภาษา ชื่อตัวละคร) กด **เลือกเกม** เป็นเกมใหม่จะสร้างโปรไฟล์ใหม่ให้
  และเดาภาษาจากชื่อหน้าต่างเกม (ถ้าเดาผิดเปลี่ยนที่ช่องภาษาในเกม) ไม่ทับของเกมเดิม
- เปิดเกมไหน game-lens สลับไปใช้โปรไฟล์ของเกมนั้นเอง
- ตัวอ่านภาษาเกาหลีมีมาในรุ่น portable แล้ว ถ้าติดตั้งจากโค้ด จะดาวน์โหลดเองตอนอ่านเกาหลีครั้งแรก (ต้องมีเน็ต)
- ทดสอบกับเกมจริงแล้วเฉพาะภาษาญี่ปุ่น เกาหลีและจีนทดสอบกับภาพที่วาดบทพูดเลียนแบบเกม

## ระหว่างเล่น

| ปุ่ม | ทำอะไร |
|---|---|
| F8 (กดค้าง) | ดูต้นฉบับญี่ปุ่น |
| Ctrl+F8 | หยุด / เริ่มแปล |
| F9 | แปลทั้งหน้าจอ (เมนู คำอธิบายไอเทม) กดอีกครั้งหรือ Esc เพื่อปิด |
| F10 | ตั้งกรอบข้อความ |
| F7 | ประวัติคำแปล + ปุ่มสร้าง glossary ชื่อตัวละคร |

- **เมนู / เควสต์:** กด F9 เพื่อแปลทั้งหน้าจอ หรือติ๊ก "แปลเมนู / เควสต์เองเมื่อหน้าจอนิ่ง" ในหน้าต่าง game-lens
  แล้วโปรแกรมจะแปลให้เองเมื่อภาพทั้งจอหยุดนิ่งประมาณ 0.7 วินาที (เช่น เปิดเมนู) และลบออกเมื่อหน้าจอเปลี่ยน
  เมนูที่มีพื้นหลังขยับตลอดจะไม่ถูกจับ ให้กด F9 แทน โหมดนี้ใช้เครื่องแปลมากขึ้น ระวังโควตาถ้าใช้ API
- จุดสามจุดที่มุมกรอบ = กำลังแปล
- ข้อความสั้นๆ ด้านบนจอเกม = สถานะหรือปัญหา (ปิดได้ในหน้าต่าง game-lens)
- ปิดหน้าต่าง game-lens ได้ โปรแกรมยังทำงานอยู่ที่ไอคอน 訳 มุมขวาล่าง คลิกไอคอนเพื่อเปิดหน้าต่างอีกครั้ง
- ปุ่มลัดแก้ได้ใน `settings.json`

## เครื่องแปล

เลือกในหน้าต่าง game-lens ถ้าต้องใช้ key ให้วาง key ในช่องแล้วกด **บันทึก key** โปรแกรมจะทดสอบให้ทันที

| เครื่องแปล | หมายเหตุ |
|---|---|
| โมเดลแปลในเครื่อง (ค่าเริ่มต้น) | ฟรี ไม่ต้องใช้เน็ต เลือกรุ่นตามการ์ดจอให้เอง (ดูด้านล่าง) |
| Gemma 26B | ในเครื่อง แปลสวยที่สุด แต่ใช้การ์ดจอมาก |
| Google ฟรี | ไม่ต้องสมัคร ใช้ช่องทางเดียวกับ LunaTranslator (ของฟีเจอร์แปลหน้าเว็บใน Chrome) ไม่เป็นทางการ อาจใช้ไม่ได้เมื่อไหร่ก็ได้ |
| DeepL | ฟรี 500,000 ตัวอักษร/เดือน ต้องสมัคร DeepL API Free |
| Microsoft Azure | ฟรี 2,000,000 ตัวอักษร/เดือน (แผน F0) |
| Google Cloud / Claude | ใช้ key |

- **โมเดลในเครื่องรุ่นไหน:** การ์ดจอ 10 GB ขึ้นไปใช้ Index-Translate 9B (ภาษาเป็นธรรมชาติที่สุดในการทดสอบกับเกม
  ~0.6 วินาที/ประโยค ใช้การ์ดจอ ~5.5 GB) น้อยกว่านั้นใช้ Hy-MT2 1.8B (~0.3 วินาที ใช้การ์ดจอ ~2 GB แปลด้อยกว่า)
  ไม่มีการ์ดจอแยกใช้ Hy-MT2 1.8B บน CPU (~0.8–2 วินาที) เลือกเองได้ที่ช่อง **รุ่นโมเดล** (มี Hy-MT2 7B ด้วย)
  เปลี่ยนแล้วสลับให้ทันที รุ่นที่ยังไม่มีจะดาวน์โหลดเอง
- key ถูกเก็บในเครื่องนี้เท่านั้น ที่ `server/data/keys.json`
- ถ้าเครื่องแปลออนไลน์ใช้ไม่ได้ จะเปลี่ยนไปใช้โมเดลในเครื่องเอง
- ประโยคที่เคยแปลแล้วจะขึ้นทันทีจาก cache ไม่เสียโควตาซ้ำ
- ชื่อตัวละครใน glossary ถูกแปลเหมือนกันทุกเครื่องแปล
- **glossary ของ Azur Promilia** อยู่ที่ `glossaries/azur-promilia.th.json` แก้ช่อง `tl` เพื่อเปลี่ยนวิธีเขียนชื่อ แล้วเปิด game-lens ใหม่
  ชื่อตัวละครเขียนเป็นอักษรโรมันตามเว็บทางการไทย ช่อง `source` บอกว่าชื่อไหนมาจากเว็บทางการ (`official`) หรือเว็บแฟน (`fan`)
  เกมอื่น: สร้างไฟล์ `glossaries/<series>.<ภาษา>.json` แบบเดียวกัน (`series` อยู่ในไฟล์ profile)

## ถ้ามีปัญหา

- **แปลช้า:** ดู `nvidia-smi` ถ้ามีโปรแกรมอื่น (เช่น ComfyUI) ใช้การ์ดจออยู่ โมเดลในเครื่องจะช้าลงหลายเท่า
  ปิดโปรแกรมนั้น หรือเปลี่ยนไปใช้ Google / DeepL / Azure ซึ่งไม่ใช้การ์ดจอ
- **คำแปลขึ้นก่อนประโยคจบ:** game-lens อ่านบรรทัดซ้ำเองและเปลี่ยนเป็นคำแปลเต็มเมื่อเกมพิมพ์ต่อ ไม่ต้องตั้งค่าอะไร
- **บทพูดบรรทัดที่ 3 ไม่ถูกแปล:** กด F10 แล้วลากขอบล่างของกรอบบทพูดลงให้ครอบ 3 บรรทัด
- **กดข้ามบทพูดเร็ว (ไม่ถึงราว 2 วินาที) แล้วไม่มีคำแปล:** คำแปลใช้เวลา 1-2 วินาทีหลังเกมพิมพ์จบ บรรทัดที่ถูกข้ามก่อนนั้นจะไม่ขึ้น
- **เมนูแปลเองช้าลงตอนมีบทพูดอยู่บนจอ:** ตั้งใจให้เป็นแบบนั้น การอ่านทั้งจอจะทำให้บทพูดแปลช้า ถ้ารีบกด F9 ได้ทันที
- **ขอบสีเหลืองรอบหน้าต่างเกม:** เป็นของ Windows 10 เวลาจับภาพหน้าต่าง ปิดไม่ได้ (Windows 11 ไม่มี)
- **รายละเอียด:** `logs/gamelens.log`, `logs/server.log`

## Dev

```powershell
.venv\Scripts\python.exe -m pytest tests -q                                             # client
.venv\Scripts\python.exe -m pytest server/tests -q                                      # server
.\start.ps1 -Quit                                                                       # ปิด game-lens
.venv\Scripts\python.exe tools\render_screen.py shot.png out.png                        # ดูว่า F9 จะวาดอะไรบนภาพหน้าจอ (ต้องเปิด game-lens อยู่)
```

ทดสอบกับวิดีโอที่อัดจากเกม (ไม่ต้องเปิดเกม): เล่นคลิปผ่านระบบจับบทพูดจริง แล้วรายงานว่าจับได้กี่บรรทัด คำแปลขึ้นช้าแค่ไหน
พร้อมภาพก่อน/หลังของทุกบรรทัด และแยกบรรทัดที่มีปัญหาไว้ใน `problems/` ใส่ `--save-video` ถ้าอยากได้คลิปที่มีคำแปลทับ
`--size 2560x1440` ทดสอบเหมือนเปิดเกมขนาดอื่น, `--times 0.25,0.35,0.028` ใช้เวลาอ่าน/แปลคงที่ ผลจะไม่ขึ้นกับโปรแกรมอื่นที่เปิดอยู่, `--segments ไฟล์` เล่นหลายช่วง (บรรทัดละ `12:30 - 13:05`)
พิกัดของกรอบเป็นพิกเซลของวิดีโอ ตัวอย่างนี้ใช้กับบทพูดเนื้อเรื่องที่ 1920x1080

## โครงสร้าง

- `gamelens/` ตัวแอป (หน้าต่าง, จับภาพ, overlay)
- `server/` ระบบอ่านข้อความ (PP-OCR) และแปล ทำงานที่ `127.0.0.1:9960` แอปเปิดและปิดให้เอง
- โมเดลแปลในเครื่องอยู่ที่โฟลเดอร์กลาง `D:\AI\models\Hy-MT2-7B-Q4_K_M.gguf` (เปลี่ยนได้ที่ `models_dir` ใน `settings.json`; ต้องมี `llama` ใน PATH)
- `server/data/` cache คำแปล, glossary, key (อยู่ในเครื่องนี้เท่านั้น)
